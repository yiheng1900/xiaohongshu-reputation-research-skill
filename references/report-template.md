# Management Report Template

Use this structure for management-facing output. The tone should be objective, restrained, and problem-solving oriented.

## Required Sections

1. 执行摘要
2. 样本概况
3. 总体口碑判断
4. 正面评价 Top 5
5. 负面问题 Top 5
6. 高频购买顾虑
7. 售后与交付风险
8. 不同用户阶段关注点
9. 典型用户原话
10. 对产品、服务、门店运营的优化建议
11. 调研局限性
12. 结论与最优先解决的 3 个问题

## Analysis Guardrails

- State raw sample count, valid sample count, core sample count, note count, comment count, and reply count separately.
- Use core sample as the default denominator for sentiment and dimension charts unless a section says otherwise.
- For multi-label dimensions, say that percentages do not sum to 100%.
- Distinguish "appears in this Xiaohongshu sample" from "all customers".
- Avoid claiming causality unless evidence directly supports it.
- Explain whether negative issues are incidents, repeated patterns, or无法判断.
- Link every Top 5 positive and negative finding back to sample IDs and Xiaohongshu source URLs. If a finding has no available URL, mark it as `链接不可见` and do not use it as the lead example.
- Report marketing/advertising content as a limitation or content pattern, not as real user satisfaction.

## Sample Overview Metrics

Include:

- Total raw samples.
- Valid samples.
- Core samples.
- Notes/comments/replies.
- Sentiment distribution.
- Authenticity level distribution.
- City/store distribution when available.
- Publish time distribution when available.
- Top dimensions by count and percentage.

## Positive Top 5 Format

For each point:

- Positive point.
- Frequency and denominator.
- Evidence strength.
- Representative quote.
- Evidence links: include 1-3 representative sample IDs with clickable Xiaohongshu URLs. Prefer A/B authenticity samples. Use a compact table with columns `样本ID`, `来源类型`, `代表原话`, `小红书链接`.
- User stage involved.
- Operational implication: what the brand, product, store, or service team can learn from this positive pattern. Keep it as operating insight, not marketing copy.

## Negative Top 5 Format

For each issue:

- Negative issue.
- Frequency and denominator.
- Representative quote.
- Evidence links: include 1-3 representative sample IDs with clickable Xiaohongshu URLs. Prefer A/B authenticity samples and independent notes/users. Use a compact table with columns `样本ID`, `来源类型`, `代表原话`, `小红书链接`.
- Process stage: quote, design, delivery, installation, after-sales, product, store service, etc.
- Whether it appears systemic.
- Business impact.
- Suggested fix.

## Optimization Advice

Every recommendation should map back to a user feedback pattern. Avoid generic advice such as "improve service" unless it is translated into an operational action:

- What should change.
- Which user feedback supports it.
- Which team owns it.
- What metric should improve.

## Limitations Section

Always include:

- Xiaohongshu platform and algorithm bias.
- Positive content may include commercial seeding.
- Negative content may be emotionally amplified.
- User identity cannot always be verified.
- City/store execution may vary.
- Public Xiaohongshu content is not a full satisfaction survey.
- Sampling, access, and deleted/private content limitations.
